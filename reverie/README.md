# Rêverie

**Le voyage qui vous ressemble.** Rêverie trouve le voyage idéal à partir des envies de chaque voyageur, pas à partir d'une destination.

## Lancer le site en local

```bash
cd reverie
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Vérifier que tout marche

```bash
npm test        # tests unitaires
npm run e2e     # parcours complet dans un navigateur
npm run lint && npm run typecheck && npm run build
```

Voir `CLAUDE.md` pour l'organisation du code et l'avancement.
